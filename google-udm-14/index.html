What Is udm=14? Google Web Results Only

If you have seen people share a "secret" Google link that shows plain results with no AI Overview, that is udm=14. Here is what the parameter actually does, the other udm values, and how to make every search use it automatically.

3 min read Updated June 2026 Free to use

What udm=14 means

udm is the parameter Google uses to choose which results "mode" to show. The value 14 is the Web filter: classic web links, no AI Overview, no generative summary, no extra modules. Adding &udm=14 to a Google search URL gives you a clean, fast results page.

udm=14Web, plain links, no AI Overview
udm=2Images
udm=7Videos
udm=12News
udm=18Forums

The exact list shifts over time as Google adds modes, but udm=14 has reliably meant Web-only results.

Why people use it

  • No AI Overview: the generative summary box is gone, so real links are at the top.
  • Faster: the page skips the slow AI generation step.
  • Less clutter: no shopping, knowledge, or "people also ask" modules crowding the results.

How to use it on every search

You can add &udm=14 by hand, but that gets old fast. Two better options:

  1. Custom search engine In your browser settings, add a search engine with https://www.google.com/search?q=%s&udm=14 and set it as default. Address-bar searches then load Web results, but links you click elsewhere still bypass it.
  2. VanishAI (covers everything) Install the free VanishAI extension. It adds udm=14 to every Google search automatically, including searches you reach from other sites, and you can toggle it off anytime.

Why not a CSS "AI hider"? Extensions that hide the AI Overview with styling break whenever Google changes class names. udm=14 uses Google's own filter, so it stays stable.

Frequently asked questions

Does udm=14 still work?

Yes. It is Google's own Web-results parameter, so it is stable and does not depend on page layout.

Will it remove Images or Maps?

No. udm=14 only applies to the search you add it to. Image, Video, and Map searches work normally, and VanishAI leaves them alone.
